# Purpose

This document defines the navigation philosophy for Project Clarity.

Navigation should help visitors move naturally through the website with
minimum effort and minimum distraction.

The objective is simplicity.

---

# Navigation Philosophy

The navigation should disappear into the experience.

Visitors should remember the content.

Not the menu.

Navigation should feel:

• Clean

• Predictable

• Minimal

• Fast

• Familiar

Every menu item must earn its place.

---

# Primary Navigation

The primary navigation consists of only five pages.

• Home

• About

• Clarity Consultation

• Articles

• Contact

This navigation should remain stable.

Adding pages should be considered carefully.

# Header Behaviour

The header should remain consistent across every page.

Requirements

• Fixed navigation

• Lightweight

• Clean

• Mobile responsive

• Accessible

No page should have a different header.

---

# Active Navigation

The currently active page should be visually highlighted.

Visitors should always know where they are.

---

# Mobile Navigation

The mobile experience should be intentionally designed.

Requirements

• Hamburger menu

• Large touch targets

• Simple transitions

• Easy dismissal

Avoid complicated nested menus.

---

# Footer Navigation

The footer complements the primary navigation.

Suggested links:

Home

About

Clarity Consultation

Articles

---

# Logo Behaviour

Clicking the logo should always return to:

Home

The logo represents the brand.

It should remain visible on every page.

---

# Call To Action

The primary CTA should remain consistent throughout the website.

Preferred wording:

Request a Clarity Consultation

Do not change wording between pages.

Consistency builds familiarity.

---

# Internal Linking Principles

Every page should naturally guide visitors to another relevant page.

Examples

Home

↓

About

↓

Consultation

↓

Consultation Request

Articles

↓

Related Articles

↓

Consultation

↓

Contact

The visitor should never reach a dead end.

---

# Navigation Rules

Always

✓ Keep it simple.

✓ Keep labels short.

✓ Maintain consistency.

✓ Support mobile users.

✓ Prioritise clarity.

Never

✗ Add unnecessary menu items.

✗ Create multiple navigation styles.

✗ Hide important pages.

✗ Overcomplicate the experience.

---

# Accessibility

Navigation should support:

• Keyboard navigation

• Screen readers

• Visible focus states

• High contrast

• Mobile accessibility

Accessibility is a core requirement.

---

# Future Navigation

Future pages should only be added when they genuinely improve the
visitor experience.

Potential future additions:

Books

Courses

Speaking

Resources

Newsletter

Client Portal

These should not appear until they are fully developed.

---

# Success Checklist

✓ Navigation is intuitive.

✓ Visitors always know where they are.

✓ Primary CTA remains visible.

✓ Mobile navigation is easy to use.

✓ Internal linking encourages exploration.

✓ No unnecessary complexity.
