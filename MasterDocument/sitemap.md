# Purpose

This document defines the complete information architecture (IA) of the
Project Clarity website.

It serves as the master reference for:

• Navigation

• Internal linking

• User journeys

• SEO structure

• Future expansion

Every new page should fit naturally into this structure.

---

# Website Principles

The website is intentionally small.

Every page must have a clear purpose.

Visitors should never feel overwhelmed.

Navigation should remain simple.

Trust should increase with every page.

---
