Version: 1.0

# Purpose

This document defines the exact UI composition of Project Clarity.

While the Design System defines how components should look,
this document defines:

• What appears on every page

• The order of sections

• Layout principles

• Component hierarchy

• Spacing philosophy

• User flow

This document is intended to make the website reproducible from scratch.

---

# Global Layout

Every page follows the same overall structure.

```
Header

↓

Hero

↓

Content Sections

↓

Primary Call To Action

↓

Footer
```

The order should remain consistent across the website.

---

# Global Container

Content should remain centered.

Readable line length.

Comfortable whitespace.

No full-width text blocks.

---

# Header

Appears on every page.

Contains:

Logo

Sticky Header

# Cards

Used for:

Articles

Highlights

Information

Cards should remain visually light.

---

# Images

Images should support the content.

Never replace the content.

Portraits should feel natural.

Avoid decorative imagery.

---

# Forms

Labels above fields.

Consistent spacing.

Clear validation.

Large textarea for questions.

Accessible controls.

---

# Mobile Behaviour

Single-column layout.

Collapsible navigation.

Comfortable touch targets.

Readable typography.

Maintain section order.

---

# Desktop Behaviour

Centered content.

Balanced whitespace.

Images aligned with text where appropriate.

No unnecessary empty areas.

---

# Accessibility

Semantic HTML.

Keyboard navigation.

Visible focus states.

Alt text for all meaningful images.

Colour contrast compliant.

---

# Performance

Optimised images.

Minimal JavaScript.

Reusable CSS components.

Fast loading.

No unnecessary animations.

---

# Visual Rhythm

Every page should alternate naturally between:

Text

↓

Whitespace

↓

Image (where applicable)

↓

Content

↓

CTA

Avoid repetitive layouts.

---

# CTA Placement

Every major page should contain one primary CTA.

The CTA should appear naturally after the visitor has received sufficient information.

Never interrupt educational content with repeated sales prompts.
