Version: 1.0

# Purpose

This document defines the visual and UI standards for Project Clarity.

Its purpose is to ensure consistency across every page of the website.

Every design decision should support the principles defined in
**brand-foundation.md**.

The design system exists to create a calm, trustworthy and timeless user
experience.

---

# Design Principles

Every interface should feel:

• Calm

• Spacious

• Professional

• Elegant

• Accessible

• Minimal

Content should always be the primary focus.

---

# Layout

The website follows a consistent page structure.

```
Header

↓

Hero

↓

Content Sections

↓

Call To Action

↓

Footer
```

Every page follows this pattern unless there is a strong reason not to.

---

# Grid

Responsive layout.

Content centred.

Consistent maximum content width.

Generous whitespace on both desktop and mobile.

---

# Spacing

Spacing should create rhythm.

Use consistent spacing throughout the website.

Prefer generous spacing over crowded layouts.

No section should feel compressed.

---

# Typography

Typography should communicate clarity.

Requirements

• Excellent readability

• Strong hierarchy

• Comfortable line length

• Consistent spacing

Avoid decorative fonts.

---

# Heading Hierarchy

Each page should contain:

One H1

Multiple H2 sections

H3 where required

Never skip heading levels unnecessarily.

---

# Paragraphs

Keep paragraphs short.

Ideal:

2–5 lines.

Avoid long walls of text.

---

# Colour Usage

Colours should support content.

Never dominate it.

Use colours consistently for:

Primary actions

Links

Highlights

Borders

Backgrounds

---

# Buttons

Primary Button

Used for:

Request a Clarity Consultation

Secondary Button

Used for:

Learn More

Read Articles

Contact

All buttons should maintain consistent:

Padding

Border radius

Typography

Hover behaviour

---

# Forms

Forms should remain:

Simple

Clean

Accessible

Consistent

Every form field should include:

Visible label

Placeholder (where helpful)

Validation

Clear error messages

---

# Input Fields

Maintain consistent:

Height

Padding

Border radius

Focus state

Spacing

Validation styling

---

# Cards

Cards should be used for:

Articles

Highlights

Information blocks

Cards should feel:

Clean

Lightweight

Readable

Avoid excessive shadows.

---

# Images

Use authentic photography only.

Image naming convention:

```
assets/images/

hero/
about/
consultation/
articles/
general/
```

Examples

jinesh-hero.jpg

jinesh-about.jpg

consultation-session.jpg

---

# Image Rules

Images should be:

High quality

Optimised

Professionally lit

Natural

Consistent

Avoid:

Stock imagery

Astrology clichés

Artificial editing

---

# Icons

Use icons only when they improve understanding.

Icons should be:

Simple

Consistent

Minimal

Never decorative.

---

# Links

Links should clearly indicate interaction.

Maintain consistent hover behaviour.

Avoid underlining large amounts of text.

---

# Section Design

Every section should contain:

Heading

Supporting text

Primary content

Optional CTA

Consistent vertical spacing

---

# Hero Sections

Every hero should contain:

H1

Supporting paragraph

Primary CTA

Optional secondary CTA

Optional image

Never overcrowd the hero.

---

# Navigation

Consistent across every page.

Header

Logo

Navigation

Primary CTA (if applicable)

Footer

Standard footer on every page.

---

# Responsive Design

The website is mobile-first.

Every page must remain:

Readable

Comfortable

Functional

Accessible

No horizontal scrolling.

---

# Accessibility

Every page should include:

Semantic HTML

Alt text

Keyboard navigation

Visible focus states

Readable colour contrast

Accessibility is a requirement.

---

# Performance

Optimise:

Images

CSS

JavaScript

Fonts

Avoid unnecessary libraries.

Prefer simplicity.

---

# Consistency Rules

Every page should feel like part of the same website.

Maintain consistency in:

Typography

Buttons

Forms

Spacing

Cards

Navigation

Footer

CTAs

---

# Design Checklist

Before approving any page, verify:

✓ Layout is clean.

✓ Typography is readable.

✓ Images are authentic.

✓ Buttons are consistent.

✓ Forms are accessible.

✓ Mobile experience is excellent.

✓ Whitespace is generous.

✓ Design supports trust.
