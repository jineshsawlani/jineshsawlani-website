# contact.md

Version: 1.0

Project: Project Clarity
Status: Page Specification

---

# Purpose

The Contact page provides visitors with a simple and professional way to
reach Jinesh Savlani.

It is intended for general enquiries.

Visitors wishing to request a consultation should be encouraged to use
the dedicated Consultation Request page.

---

# Business Goal

Primary Goal

Enable genuine communication.

Secondary Goals

• Answer general enquiries.

• Provide an alternative contact method.

• Direct consultation enquiries to the correct workflow.

---

# Target Audience

This page is intended for visitors who wish to:

• Ask a general question.

• Discuss collaborations.

• Media or speaking enquiries.

• Clarify information before requesting a consultation.

• Report a website issue.

---

# Page Philosophy

The Contact page should feel welcoming.

Not transactional.

Visitors should feel comfortable reaching out.

The page should remain clean, uncluttered and easy to use.

---

# Visitor Questions

The page should answer:

How can I contact Jinesh?

What is the best way to request a consultation?

When should I expect a reply?

---

# Page Structure

## 1. Hero

Headline

Let's Start a Conversation

Supporting copy explaining that general enquiries are welcome.

Primary CTA

Send a Message

---

## 2. Contact Information

Display:

Email Address

Location

(Pune, Maharashtra, India)

Timezone

(Optional)

Avoid displaying a personal phone number publicly unless required.

---

## 3. Contact Form

Fields

• Full Name *

• Email Address *

• Subject *

• Message *

Submit Button

Send Message

Keep the form intentionally short.

---

## 4. Consultation Notice

Clearly explain:

If you are seeking a personal astrology consultation, please use the
dedicated Consultation Request page.

Provide a button:

Request a Clarity Consultation

---

## 5. Expected Response Time

State a realistic expectation.

Example:

I aim to respond to all genuine enquiries within 2–3 business days.

Do not promise immediate replies.

---

# Form Validation

Required Fields

✓ Name

✓ Email

✓ Subject

✓ Message

Email should be validated.

Trim unnecessary whitespace.

Prevent spam submissions where possible.

---

# After Submission

Redirect to:

thank-you.html

Display confirmation that the message has been received.

---

# Email Notifications

Visitor receives:

Acknowledgement email.

Administrator receives:

Complete contact message.

Submission timestamp.

---

# Contact Guidelines

This page should not be used for:

Astrology emergencies.

Instant readings.

WhatsApp consultations.

Phone consultations.

Visitors seeking a consultation should always be directed to the proper
consultation workflow.
