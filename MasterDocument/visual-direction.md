# visual-direction.md

Version: 1.0

Project: Project Clarity
Status: Brand Visual Guidelines

---

# Purpose

This document defines the visual identity of Project Clarity.

The objective is to ensure every visual element communicates the same
values as the brand.

The design should immediately communicate:

• Trust

• Simplicity

• Clarity

• Professionalism

• Timelessness

The website should never feel trendy.

It should feel enduring.

---

# Design Philosophy

The design should disappear.

Visitors should remember the ideas.

Not the animations.

Not the colours.

Not the effects.

Good design supports communication.

It never competes with it.

---

# Brand Personality

Every visual decision should reinforce:

Calm

Thoughtful

Elegant

Professional

Minimal

Authentic

Warm

Confident

---

# Overall Feel

When someone lands on the website, they should think:

"This feels different."

"This feels trustworthy."

"This feels premium."

"This feels peaceful."

Not:

"This feels busy."

"This feels flashy."

"This feels like marketing."

"This feels like every other astrology website."

---

# Design Inspiration

The overall experience should be inspired by companies known for clarity
and thoughtful design.

Examples include:

• Apple

• Stripe

• Linear

• Notion

• Medium

Not because they look similar,
but because they communicate confidence through simplicity.

---

# Colour Philosophy

Colours should support the content.

Never dominate it.

The overall palette should feel:

Light

Warm

Minimal

Timeless

Comfortable

Whitespace should be the dominant visual element.

---

# Colour Usage

Primary Colour

Used for:

Buttons

Links

Highlights

Secondary Colour

Used sparingly for supporting elements.

Neutral Colours

Used for:

Backgrounds

Text

Borders

Cards

The interface should never become colourful simply for decoration.

---

# Typography

Typography is one of the strongest parts of the visual identity.

Requirements:

• Excellent readability

• Clear hierarchy

• Generous spacing

• Comfortable line length

Avoid decorative fonts.

Content should always remain the hero.

---

# Layout Philosophy

Every page should feel spacious.

Avoid:

Crowded layouts.

Large blocks of text.

Too many columns.

Competing sections.

The eye should naturally know where to go next.

---

# White Space

White space is not empty space.

It improves readability.

It creates calm.

It communicates confidence.

Never reduce spacing simply to fit more content.

---

# Photography

Photography should always feel authentic.

Use real photographs.

Never use stock images if they can be avoided.

The person is the brand.

Photography should communicate:

Approachable

Professional

Thoughtful

Natural

Warm

---

# Image Style

Natural lighting.

Neutral backgrounds.

Minimal distractions.

Real environments.

Comfortable posture.

Relaxed expression.

No dramatic editing.

No heavy filters.

No artificial effects.

---

# Images To Capture

Hero Portrait

About Portrait

Consultation Portrait

Working / Study Desk

Speaking / Teaching

Reading Classical Texts

Professional Lifestyle

These images should be sufficient for the entire website.

---

# Icons

Icons should remain minimal.

Use only where they improve understanding.

Avoid decorative iconography.

---

# Animations

Animations should be subtle.

Purpose:

Guide attention.

Provide feedback.

Improve experience.

Never animate for entertainment.

Avoid:

Parallax.

Flying elements.

Complex transitions.

Heavy motion effects.

---

# Cards

Cards should feel clean.

Light borders.

Soft shadows (if any).

Comfortable spacing.

Simple typography.

No visual clutter.

---

# Buttons

Buttons should be easy to recognise.

Simple.

Readable.

Consistent.

Primary CTA should remain visually consistent across the website.

---

# Mobile Design

Mobile is not a reduced desktop experience.

Every page should be intentionally designed for smaller screens.

Maintain:

Whitespace.

Readable typography.

Comfortable touch targets.

Simple navigation.

---

# Accessibility

Design should support everyone.

Maintain:

Readable colour contrast.

Keyboard accessibility.

Clear focus states.

Meaningful alt text.

Responsive layouts.

Accessibility is part of quality.

---

# Things To Avoid

Do not use:

Crystal balls.

Zodiac wheels.

Galaxy backgrounds.

Mystical symbols.

Astrology clipart.

Flashing banners.

Gold gradients.

Heavy textures.

Overly spiritual imagery.

Project Clarity is built around the person,
not astrology clichés.

---

# Visual Checklist

Before approving any design, ask:

✓ Does this build trust?

✓ Does this feel calm?

✓ Is the layout spacious?

✓ Are images authentic?

✓ Is readability excellent?

✓ Does anything distract from the message?

✓ Does this feel timeless?
