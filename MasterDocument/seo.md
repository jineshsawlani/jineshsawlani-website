# Purpose

This document defines the Search Engine Optimisation (SEO) strategy for
Project Clarity.

The objective is to improve discoverability while maintaining the core
philosophy of the brand.

SEO should never compromise readability, trust or user experience.

---

# SEO Philosophy

Write for people first.

Optimise for search engines second.

Every page should answer a genuine question.

Never create content purely to rank.

Trust is a long-term SEO strategy.

---

# Primary SEO Goal

Build authority around:

**Jinesh Savlani**

The website should establish the personal brand first.

Service pages and articles should support this objective.

---

# Secondary Goals

• Build topical authority in Classical Vedic Astrology.

• Generate organic consultation enquiries.

# Meta Descriptions

Every page should have a unique meta description.

Length

Approximately 140–160 characters.

The description should naturally explain the page.

Avoid keyword stuffing.

---

# URL Structure

Use:

Lowercase

Hyphens

Short URLs

Examples

/

clarity-consultation-request.html

articles.html

contact.html

privacy-policy.html

disclaimer.html

terms-and-conditions.html

---

# Heading Structure

Every page should contain:

One H1

Logical H2 sections

H3 headings where required

Maintain semantic hierarchy.

---

# Images

Every image should include:

Meaningful filename

Descriptive alt text

Optimised file size

Examples

Good

jinesh-hero.jpg

consultation-session.jpg

about-jinesh.jpg

Poor

image1.jpg

photo.jpg

final.png

---

# Alt Text

Alt text should describe the image naturally.

Example

"Jinesh Savlani during a Classical Vedic Astrology consultation."

Avoid keyword stuffing.

---

# Internal Linking

Every major page should naturally link to:

Home

About

Clarity Consultation

Articles

Contact
